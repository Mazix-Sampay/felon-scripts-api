Скрипты Felon на Lua

Кладёшь .lua в Felon/scripts, включаешь во вкладке Scripts в ClickGUI - и скрипт получает события игры, рисует на экране и в мире, управляет модулями.

Lua 5.2 (LuaJ)песочницагорячая перезагрузкаконсоль и ошибки во вкладке

Быстрый старт

ClickGUI → Scripts → Папка, создай hello.lua, нажми Обновить и включи переключателем.

script = { name = "Привет", author = "я", description = "Первый скрипт" }

events.on("enable", function()
  client.print("Скрипт включён!")
end)

events.on("render2d", function()
  render.text("Hello, Felon!", 10, 10, 9, color(255, 255, 255))
end)

Описание скрипта

Необязательная глобальная таблица script - что показывать в списке. Без неё имя берётся из имени файла.

script = { name = "...", author = "...", description = "..." }
название, автор и описание во вкладке Scripts

События

events.on(имя, функция) - на одно событие можно повесить несколько функций.

events.on("tick", fn)
каждый тик игры, 20 раз в секунду
events.on("render2d", fn)
каждый кадр - рисование на экране
events.on("render3d", fn)
каждый кадр - рисование в мире
events.on("chat", fn(text))
сообщение в чат; вернуть true - скрыть его
events.on("key", fn(key, action))
клавиша (GLFW-код); action: 1 нажата, 0 отпущена
events.on("enable" | "disable", fn)
скрипт включили / выключили
events.on("chat", function(text)
  if text:find("купи донат") then return true end -- скрыть
end)

client

client.print(text)
сообщение в чат, видно только тебе
client.say(text)
написать в чат сервера
client.command(cmd)
выполнить команду: "spawn" или "/spawn"
client.fps()
текущий FPS
client.time()
время в миллисекундах
client.server()
адрес сервера, "" в одиночной игре
client.screen()
открытый экран, "" - ничего не открыто
print(...)
строка в Консоль вкладки Scripts

player

player.exists()
true, если игрок в мире
player.name()
ник
player.pos()
x, y, z
player.velocity()
скорость x, y, z (блоков за тик)
player.yaw() / player.pitch()
поворот камеры
player.setRotation(yaw, pitch)
повернуть камеру
player.health() / player.absorption()
здоровье, поглощение
player.food()
голод 0-20
player.onGround()
стоит ли на земле
player.sprinting() / player.setSprinting(b)
спринт
player.jump()
прыжок, если на земле
player.slot() / player.setSlot(1-9)
слот хотбара
player.item([slot 1-36])
предмет в руке или слоте: id, count
player.attack()
ударить сущность под прицелом
player.use()
использовать предмет в руке

world

world.players()
игроки рядом (без тебя)
world.entities([radius])
сущности в радиусе, по умолчанию 32
world.block(x, y, z)
id блока, например "minecraft:stone"
world.dimension()
измерение, например "minecraft:the_nether"
-- элемент players() / entities():
{ name = "Nick", type = "minecraft:player", x = 0, y = 64, z = 0, distance = 5.2, health = 20 }

modules

modules.list()
имена всех модулей
modules.isEnabled(name)
включён ли модуль
modules.setEnabled(name, b) / modules.toggle(name)
включить / выключить / переключить
modules.get(name, setting)
значение настройки: boolean, number или string
modules.set(name, setting, value)
изменить настройку
modules.setEnabled("KillAura", true)
modules.set("KillAura", "Attack Range", 3.2)
modules.set("NoSlow", "Item Mode", "Adaptive")

render

На экране - только внутри render2d, в мире - только внутри render3d.

render.rect(x, y, w, h, color[, radius])
прямоугольник со скруглением
render.text(text, x, y[, size, color])
текст, размер 8 и белый по умолчанию
render.width(text[, size])
ширина текста
render.screenWidth() / render.screenHeight()
размер экрана
render.box(x1, y1, z1, x2, y2, z2, color[, fill])
коробка в мире; fill = true - залитая
render.line(x1, y1, z1, x2, y2, z2, color)
линия в мире

input

input.isKeyDown(key)
зажата ли клавиша: "r", "space", "left.shift" или GLFW-код

timer

timer.after(ms, fn)
один раз через ms миллисекунд
timer.every(ms, fn)
каждые ms миллисекунд (минимум 50)

color

color(r, g, b[, a])
цвет для render.*; a по умолчанию 255. Можно и числом: 0xFFFFFFFF

Ограничения

Скрипты работают в песочнице: нет доступа к файлам, ОС и Java (io, os, luajava, require, load, dofile). У каждого события есть лимит инструкций - бесконечный цикл не повесит игру, скрипт остановится с ошибкой. Ошибка выключает обработчики скрипта; исправь файл и нажми Обновить. Доступны string, table, math, bit32.
